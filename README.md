# AI Meeting Assistant

An automated meeting intelligence assistant that processes raw meeting transcripts, synthesizes executive summaries, pinpoints team decisions, extracts action items with assignees/deadlines, and generates follow-up recap emails.

Part of the **50 AI Automation Projects Portfolio** by [ERHA TECHNOLOGIES](https://github.com/erhatechnologiesai).
